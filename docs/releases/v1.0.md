## ZRightClick 1.0 · 首个公开版本

为 Finder 加上常用操作：新建文件、复制路径，以及在当前位置打开你选择的终端。

### 功能

- **新建文件**：两级菜单，内置 TXT、Markdown、Word、Excel 和 PowerPoint 类型，附带图标。Office 空白文档无需安装 Office 即可创建。
- **自定义类型**：通过后缀添加空文件类型；内置类型可启用或停用，自定义类型可添加、删除。
- **复制路径**：支持同时复制多个选中文件或文件夹的路径。
- **自选终端**：支持系统 Terminal、iTerm2、Ghostty 和 Warp；所选应用不可用时，本次回退系统终端。
- **菜单栏常驻**：关闭设置窗口后隐藏 Dock 图标，应用继续运行；从菜单栏重新打开设置或退出。
- **中英文切换**：设置界面、菜单栏和 Finder 菜单同步切换，自动保存选择。
- **持久目录授权**：通过系统文件夹选择器授权，保存后复用；主应用和扩展均保留 App Sandbox。

### 下载与安装

要求 **macOS 15 及以上**。安装包同时包含 **arm64 与 x86_64**，适用于 Apple 芯片和 Intel Mac。

| 附件 | 用途 |
| --- | --- |
| `ZRightClick-1.0-universal.dmg` | 推荐：打开后把应用拖入“应用程序”。内含中英文安装说明。 |
| `ZRightClick-1.0-universal.zip` | 解压后，将 `ZRightClick.app` 移入“应用程序”。 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值。 |

1. 将应用放入“应用程序”并启动。更新已有版本时，请先退出旧版。
2. 在**系统设置 → 通用 → 登录项与扩展 → 访达扩展**中启用 ZRightClick。
3. 首次执行文件或终端操作时，选择目标文件夹或上级目录完成授权。

**签名状态：** 当前为临时签名（ad-hoc），没有 Developer ID 签名，未经 Apple 公证，也不是 Mac App Store 版本。如果 macOS 阻止打开，请先核对来源与校验值，再参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在可用时通过“隐私与安全性 → 仍要打开”处理。

### 验证与已知限制

- 已通过 Release 通用构建、主应用与扩展双架构签名/沙盒权限检查、DMG 与 ZIP 完整性检查，以及四组 Foundation 测试和 Office 模板检查。
- Intel 架构已编译并检查，未在 Intel 实机运行；也未逐一覆盖所有 macOS 版本。
- Warp 的启动请求已验证，首次设置后的实际 shell 工作目录尚未确认。
- 使用情况、权限说明与完整限制见[中文 README](https://github.com/inexom/ZRightClick#readme)和[开发文档](https://github.com/inexom/ZRightClick/blob/v1.0/docs/DEVELOPMENT.md)。

## English

The first public release adds **New File**, **Copy Path**, and **Open Terminal Here** to Finder, with configurable file types, Terminal/iTerm2/Ghostty/Warp selection, menu bar residence, saved folder access, and instant English/Chinese switching.

**Requires macOS 15+.** The DMG and ZIP contain the same universal application for **Apple silicon and Intel**. Drag the app into Applications, launch it, and enable its Finder extension in System Settings. Folder access is requested when needed and saved for reuse.

This release is **ad-hoc signed and not notarized**. It has no Developer ID signature and is not an App Store build. If macOS blocks it, verify its source and checksum, then follow [Apple's opening instructions](https://support.apple.com/102445).

Both binary architectures, sandbox entitlements, package integrity, four Foundation test suites, and Office templates were checked. Intel hardware and all supported macOS versions have not been exercised. Warp's actual shell directory after first-run setup remains unverified. See the [English README](https://github.com/inexom/ZRightClick/blob/v1.0/README.en.md) for details.
