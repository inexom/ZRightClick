## ZRightClick 1.1 · 安装体验与首次启用引导

这一版让安装和启用 Finder 右键菜单的流程更清晰。

### 更新内容

- **新的 DMG 安装界面**：大图标、拖拽箭头及中英文说明，将应用拖入“应用程序”即可安装。
- **首次启用引导**：通过 Apple 提供的接口打开系统扩展管理页面，自动检测启用状态，确认成功后进入设置。
- **未启用提醒**：扩展关闭时，设置页显示提醒；可随时从“扩展设置…”重新打开引导。
- **中英文支持**：引导文字随应用语言切换，并说明不同 macOS 版本中“访达扩展”与“文件提供程序”的名称差异。
- **开发打包清理**：打包结束后注销并移除临时构建的应用和扩展，避免产生多余的应用图标。

### 下载与安装

要求 **macOS 15 及以上**，同一安装包包含 **Apple 芯片（arm64）和 Intel（x86_64）** 两种架构。

| 附件 | 用途 |
| --- | --- |
| `ZRightClick-1.1-universal.dmg` | 推荐：拖拽安装。 |
| `ZRightClick-1.1-universal.zip` | 解压后，将 `ZRightClick.app` 移入“应用程序”。 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值。 |

更新前退出旧版，再替换“应用程序”中的 ZRightClick；已有设置和目录授权会保留。首次使用时，按引导在系统列表中开启 ZRightClick。系统开关需要用户亲自确认；完成前，Finder 右键功能暂不可用。

**签名状态：** 此版本使用临时签名（ad-hoc），**未经 Apple 公证**，没有 Developer ID 签名，也不是 Mac App Store 版本。如果 macOS 阻止打开，请确认来源及校验值后，参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在可用时通过“隐私与安全性 → 仍要打开”处理。

### 验证与限制

- 已验证 Release 通用构建、主应用与扩展双架构签名/沙盒权限、DMG/ZIP 完整性，以及四组 Foundation 回归测试和 Office 模板检查。
- 启用引导已在本机验证：打开系统列表、检测开启/关闭、完成引导及中英文切换。
- Intel 架构已编译检查，尚未在 Intel 实机运行；未逐一覆盖全部支持的 macOS 版本。
- Warp 的启动请求已验证，完成其首次设置后的实际 shell 工作目录尚未确认。

## English

ZRightClick 1.1 improves installation and initial Finder extension setup:

- A redesigned DMG with large icons, a drag-to-install arrow, and bilingual instructions.
- A first-run guide that opens Apple's extension manager and checks the actual activation state.
- A warning when the extension is disabled, with the guide available from Extension Settings.
- Chinese and English guide text, including the Finder Extensions / File Providers naming difference.
- Release packaging unregisters and removes temporary build products to avoid duplicate launcher entries.

**Requires macOS 15+.** Both downloads contain the same universal app for **Apple silicon and Intel**. Quit the old app before replacing it in Applications. Existing settings and saved folder access are preserved. Activation remains a user-controlled system setting.

This release is **ad-hoc signed and not notarized**, without a Developer ID signature or App Store distribution. If macOS blocks it, verify the source and checksum, then follow [Apple's opening instructions](https://support.apple.com/102445).

Universal builds, both architectures' signatures and sandbox entitlements, package integrity, four Foundation test suites, and Office templates were checked. The setup flow was exercised locally. Intel hardware and all supported macOS versions have not been exercised. Warp's actual shell directory after first-run setup remains unverified.

See the [中文 README](https://github.com/inexom/ZRightClick/blob/v1.1/README.md) or [English README](https://github.com/inexom/ZRightClick/blob/v1.1/README.en.md) for usage details.
